# ADR 0042: Herdr App のキーマップはエージェント向け手順で保守する

## Status

Accepted

## Context

複数の Mac で Herdr App の `Cmd+W` によるタブ閉じを解除し、New Space を `Cmd+N` から `Cmd+Shift+N` に移したい。Herdr App は差分だけのキーマップを受け付けず、カスタマイズ済みのキーマップをアップグレード時にも保持するため、新版の既定の割り当ては自動では取り込まれない。一方、少数の変更のために、既定値の取得・対話マージ・安全な書き込みを担う専用ツールを継続保守するのは割に合わない。

## Decision

[PR #484](https://github.com/toku345/dotfiles/pull/484) は専用更新ツールの追加ではなく、Claude Code や Codex CLI に渡せる[運用手順](../../README.md#herdr-app-shortcuts-macos)の追加に絞る。CLI 固有の skill は追加せず、chezmoi でキーマップを直接配布したり、自動更新したりはしない。

新しい Mac では、Herdr が生成したキーマップを起点に目的のキーだけを変更し、それ以外の割り当ては保持する。更新後は、対象 Mac で前回確認した版と今回の版の公式 macOS 既定値を比較し、追加・変更・削除を確認する。手元で変更していない割り当てには新版の変更を取り込み、独自設定との衝突はユーザーに判断を求める。比較元の版が不明、または公式の既定値を取得できない場合は、推測でマージしない。

エージェントは対象パスと差分を示し、明示承認後に既存ファイルをバックアップして書き込む。Herdr の再読み込み結果は書き込み結果と分けて確認し、実際のキー操作はユーザーが試す。

## Consequences

各 Mac に同じ判断基準を適用でき、ユーザーは上流との差分を手でマージしなくてよい。更新の自動通知は設けないため、更新後はユーザーがエージェントに確認を依頼し、比較元となる確認済みの版を記録しておく必要がある。比較作業が繰り返しの負担になった場合は、まず読み取り専用の比較だけをツール化する。
