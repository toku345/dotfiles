# plan-review-handoff

[共通手順](references/procedure.md)を読み、依頼に合う段階を行う。参照先はこの Skill ディレクトリを基準に解決する。

- prepare: 元の依頼・制約・計画・根拠を、相手に渡せる編集可能な依頼文へまとめる。
- review: 受け取った計画を元の依頼・関連根拠と照合する。
- assess: 元の作成元として、戻った指摘の採否と計画への反映を判断する。

結果は原則チャット本文で返し、手動転送待ちで止める。参照を読めなければその制限を報告し、手順を読んだと装わない。
